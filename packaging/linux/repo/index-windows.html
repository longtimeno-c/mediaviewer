Windows (PowerShell)

irm @BASE_URL@/install.ps1 | iex

Per user, with no administrator: it checks the download's SHA-256 (and, for a signed build, its signatures), puts driftwire in %LOCALAPPDATA%\Programs\Driftwire and adds that folder to your PATH. Run it again to update. To remove it:

& ([scriptblock]::Create((irm @BASE_URL@/install.ps1))) -Uninstall

x64; Windows on Arm runs it too. Or unpack @WINDOWS_ZIP@ (its SHA-256 is in SHA256SUMS) wherever it should live.
