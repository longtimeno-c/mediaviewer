driftwire

Send files to a computer nearby over Wi-Fi, or anywhere with a code, from a terminal.

Each transfer is sealed end to end, and every file is checked when it arrives. Nothing is sent or saved until the person at the terminal answers. driftwire talks to MediaViewer's Driftwire on Windows and macOS, and to another driftwire. It needs no MediaViewer.

Version @VERSION@ · Linux (@ARCHES@, glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36 and later), macOS 14 or later, Windows 10 or later

Linux: one line

curl -fsSL @BASE_URL@/install.sh | sh

It adds this signed repository to apt, dnf or zypper and installs driftwire, so it updates with the rest of the system. It shows each step before it runs it, and uses sudo for the system ones. Where there is no apt, dnf or zypper it unpacks the tarball into ~/.local instead. To remove driftwire and what the line added:

curl -fsSL @BASE_URL@/install.sh | sh -s -- --uninstall

Debian, Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @BASE_URL@/key.gpg | sudo tee /etc/apt/keyrings/driftwire.gpg > /dev/null
printf '%s\n' 'Types: deb' 'URIs: @BASE_URL@/apt' 'Suites: stable' 'Components: main' \
  'Signed-By: /etc/apt/keyrings/driftwire.gpg' | sudo tee /etc/apt/sources.list.d/driftwire.sources > /dev/null
sudo apt update && sudo apt install driftwire

Fedora (dnf), openSUSE (zypper)

sudo curl -fsSL -o /etc/yum.repos.d/driftwire.repo @BASE_URL@/driftwire.repo
sudo dnf install driftwire
sudo zypper addrepo --refresh @BASE_URL@/driftwire.repo
sudo zypper install driftwire

dnf and zypper ask once to trust the repository's key; check it against the fingerprint below.

Any other Linux: the tarball

    @TARBALLS@

SHA256SUMS, signed in SHA256SUMS.asc. Unpack it where it should live (it does not update itself):

tar -xzf @TARBALL_EXAMPLE@ --strip-components=1 -C ~/.local

macOS (Homebrew)

brew install @BREW_TAP@/driftwire

brew upgrade keeps it up to date, and brew uninstall driftwire removes it. The program is signed and notarized by its publisher.

@WINDOWS_SECTION@

Then

driftwire

It shows this computer to others nearby while it runs; type /help for the commands, or see man driftwire. It asks before anything is sent or saved.

The signing key

The apt and rpm indexes, the rpm packages and SHA256SUMS are signed with this key: key.asc (armored), key.gpg (binary).
